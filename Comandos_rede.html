Roteiro rápido: computador sem Internet

Siga esta sequência para descobrir em qual etapa a conexão está falhando.

1. Conferir o IPipconfig /all
Verifique IP, gateway e DNS.
2. Testar o gatewayping 192.168.1.1
Troque pelo IP real do roteador.
3. Testar a Internetping 8.8.8.8
Testa um IP público.
4. Testar DNSnslookup google.com
Verifica a resolução de nomes.

Atenção: ipconfig /release desconecta temporariamente a interface IPv4 ao liberar o endereço. Comandos de rede devem ser executados no CMD ou PowerShell quando indicado; nem todos funcionam diretamente na caixa Executar.

Guia de estudo • Alguns comandos exigem permissões de administrador ou variam conforme a versão do Windows.
