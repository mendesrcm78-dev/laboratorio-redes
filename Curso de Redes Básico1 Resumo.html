🌐 Módulo 1 — O que é uma Rede?

Rede = dois ou mais dispositivos interligados que compartilham dados e recursos (impressoras, arquivos, internet).

Surgimento: Anos 60 → troca de dados entre 2 PCs. 1970-73 → ARPANET interligou universidades e militares. Evoluiu até a Internet atual.

🏗️ Módulo 2 — Topologias e Arquiteturas

Ponto a Ponto (P2P): Todos os PCs iguais, sem servidor. Barato e simples. Ideal para redes pequenas.

Cliente/Servidor: Servidor central gerencia tudo. Mais seguro, sem limite de máquinas, precisa de administrador.

━━
Barramento: Todos num cabo só. Barato, mas se o cabo falha, tudo para.
⭕
Anel: Dados circulam em um sentido. Sem colisões, mas pouca tolerância a falhas.
⭐
Estrela (a mais usada!): Tudo conectado a um Switch central. Se um cabo falha, os demais funcionam.

Comunicação: Unicast 1→1 · Multicast 1→grupo · Broadcast 1→todos

🔌 Módulo 3 — Equipamentos de Rede
📦 Hub (obsoleto)
Replica sinal para TODAS as portas. Causa colisões.
🔌 Switch (o principal)
Envia dados SÓ para a porta de destino via tabela MAC.
🔀 Roteador
Conecta redes diferentes. Escolhe a melhor rota para os pacotes.
📡 Access Point
Fornece Wi-Fi. Recebe via cabo e distribui sem fio.
📞 Modem
Converte digital↔analógico. Conecta ao provedor de Internet.
🖥️ Servidor
Fornece serviços: DHCP, DNS, arquivos, e-mail, web.
🔗 Módulo 4 — Cabeamento e Meios de Transmissão

Par Trançado (UTP/STP): O mais usado. Conector RJ-45. Máximo 100 metros. UTP=sem blindagem, STP=com blindagem.

Interferências: EMI (eletromagnética), RFI (radiofrequência), Atenuação (perda por distância), Diafonia (cabos adjacentes).

📜 Módulo 7 — Protocolos de Rede

Protocolos = regras que governam a comunicação entre dispositivos na rede.

IP Identifica dispositivos com endereço único. Divide dados em pacotes.
TCP Conexão confiável. Verifica se cada segmento foi recebido.
UDP Rápido, sem garantia. Usado em voz/vídeo em tempo real.
DNS Traduz nomes (google.com) → IPs. "Agenda da internet".
HTTP/S Navegação web. HTTPS = com criptografia (cadeado).
DHCP Distribui IPs automaticamente na rede.
FTP Transferência de arquivos entre computadores.
ARP Mapeia IP → MAC. Localiza endereço físico via IP.

DNS populares: 8.8.8.8 Google · 1.1.1.1 Cloudflare · 9.9.9.9 Quad9
